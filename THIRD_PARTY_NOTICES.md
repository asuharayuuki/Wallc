# Third-party assets

## Application icon

The icon foreground is **Wallpaper**, Material Symbols Rounded, from [Google Fonts Icons](https://fonts.google.com/icons?selected=Material+Symbols+Rounded:wallpaper:FILL@0;wght@400;GRAD@0;opsz@48).

Official SVG: https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/wallpaper/default/48px.svg

Original SVG: `artwork/material-symbols/wallpaper.svg`. The path geometry is preserved in the Android vector. Uniform scaling and centered positioning provide additional padding for circular launcher masks. The same alpha geometry supplies the monochrome layer for themed icons on Android 13 and later.
